# Чек-лист перед отправкой решения

В FAIO-2025 участники теряли баллы не на моделях, а на формате файла.
Проверяйте всё это ДО того, как потратите попытку.

## Всегда

- [ ] Файл называется ровно так, как требует условие: `submission.csv`,
      `solution.csv` или `submit.csv` — это разные задачи, названия разные.
- [ ] Есть строка заголовка, названия колонок буква в букву из условия.
- [ ] Число строк совпадает с ожидаемым (`len(sub) == len(test)`).
- [ ] Порядок строк — как в тестовом файле, id начинаются с 0, если так сказано.
- [ ] Нет пропусков (`sub.isna().sum().sum() == 0`).
- [ ] Открыли файл и посмотрели на первые 5 строк глазами.

## Точное совпадение строк (задача про бейсбол, RAG)

- [ ] Ответ — строка, даже если в данных было число: `1` -> `"1"`.
- [ ] Ничего не округляли и не переформатировали: `123.4500` остаётся
      `123.4500`, а не `123.45`.
- [ ] Никаких лишних слов, точек и кавычек вокруг значения.
- [ ] Если ответа нет — ставьте заглушку из условия, а не пустоту:
      пустой файл гарантированно даёт ноль.

## Рекомендации (музыка)

- [ ] Ровно 50 треков на каждого пользователя из `test.csv`.
- [ ] Ранги 1..50, без повторов трека у одного пользователя.
- [ ] Есть колонка `id` со сквозной нумерацией:
      `recos.insert(0, 'id', range(len(recos)))`.

## Эмбеддинги (музей)

- [ ] Ровно 20 000 строк — все картинки, включая те, что кажутся лишними.
- [ ] Векторы L2-нормированы.
- [ ] Размерность одинаковая у всех строк (256 или 512).
- [ ] Колонки `ID`, `image_name`, затем `feature_0 ... feature_{D-1}`.

## Правила тура

- [ ] Ноутбук сохранён и воспроизводится с нуля: в 2025 году от финалистов
      требовали рабочий Kaggle-ноутбук для проверки после тура.
- [ ] Зафиксированы random_state / seed, иначе результат не повторится.
- [ ] Выбраны именно те сабмиты, которые идут в зачёт (обычно два).
