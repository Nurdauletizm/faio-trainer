# Рецепты для финала

Это не готовые решения, а рабочие заготовки под пять модальностей, которые
встречались в финале FAIO-2025. Их нужно править под конкретные данные:
пути к файлам, названия колонок, размеры.

| Файл | Под какую задачу | Что даёт |
|---|---|---|
| `1_tabular_gbdt.py` | Qaz-letters (таблица признаков) | бустинг + честная кросс-валидация |
| `2_text_tfidf.py` | Кто на каком языке говорит | TF-IDF на символьных n-граммах + логрег |
| `3_timeseries_imu.py` | AI Yoga Instructor (датчики) | признаки из временного ряда + бустинг |
| `4_image_shapes_count.py` | Simple Objects (счёт фигур) | контуры OpenCV без обучения |
| `5_audio_pitch.py` | Missing Fundamental (звук) | гармонический спектр, поиск f0 |
| `6_recsys_top50.py` | HearMe (музыка) | популярность + история + item-item |
| `7_embeddings_retrieval.py` | Lost in the Museum (поиск картин) | эмбеддинги DINOv2 без обучения |
| `submission_checklist.md` | все задачи | проверка формата перед отправкой |

## Главное правило тура

Сначала соберите самое простое решение целиком и отправьте его. Даже слабый
сабмит лучше пустого: в 2025 году на задаче про бейсбол 17 команд из 47
получили ровно ноль, а лучший результат был всего 0.16.

Порядок работы в туре:

1. 20 минут — прочитать условие и посмотреть на данные;
2. 40 минут — простейший бейзлайн и первый сабмит;
3. остальное время — улучшения, каждое проверять кросс-валидацией, а не
   только лидербордом;
4. последние 20 минут — не трогать код, проверить формат по чек-листу.

## Библиотеки

Всё это есть в Kaggle-ноутбуке по умолчанию: pandas, numpy, scikit-learn,
opencv, librosa, torch, timm. Локально ставится так:

```bash
pip install pandas numpy scikit-learn opencv-python librosa torch timm
```

Для тренажёра по отборочному туру (папка выше) ничего ставить не нужно.
