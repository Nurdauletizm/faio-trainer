# Тренажёр FAIO

**Открыть в браузере: https://nurdauletizm.github.io/faio-trainer/** — ничего устанавливать не нужно, Python запускается прямо на странице.

Подготовка к отборочному туру Международной олимпиады по ИИ (Fizmat AI
Olympiad, faio.kz) и к её финалу.

Задачи повторяют темы реальных туров 2024 и 2025 годов, но **генерируются
заново при каждом запуске** — одну и ту же задачу можно решать сколько угодно
раз, и списать ответ у соседа не получится. Проверка автоматическая, как на
Яндекс.Контесте: решение читает данные со стандартного ввода и печатает ответ
на стандартный вывод.

Ничего устанавливать не нужно: только Python 3 и стандартная библиотека.

## Быстрый старт

```bash
cd faio-trainer
python3 trainer.py list
python3 trainer.py show q01
```

Команда `show` открывает условие и создаёт файл `solutions/q01.py` с
заготовкой. Пишете решение в этом файле и проверяете:

```bash
python3 trainer.py check q01
```

Тренажёр прогонит решение на восьми случайных тестах. Если тест провален —
покажет входные данные, ваш вывод и правильный ответ.

## Все команды

| Команда | Что делает |
|---|---|
| `python3 trainer.py list` | список задач и прогресс |
| `python3 trainer.py show q05` | условие задачи + заготовка решения |
| `python3 trainer.py sample q05` | пример входных данных и правильного ответа |
| `python3 trainer.py check q05` | проверить своё решение |
| `python3 trainer.py check q05 --tests 30` | проверить на 30 тестах |
| `python3 trainer.py hint q05` | авторское решение — **только после своих попыток** |
| `python3 trainer.py exam` | пробный тур на 4 часа |
| `python3 trainer.py score` | результаты и остаток времени тура |
| `python3 trainer.py selftest` | самопроверка тренажёра |

## План на два дня до отбора

**День первый.** Решить q01–q05 (это час-полтора), затем q06, q07, q09.
Главная цель — довести до автоматизма чтение `sys.stdin` и вывод чисел
в нужном формате, чтобы на туре не думать об этом вообще.

**День второй.** q08, q10, q11 — это уже настоящие олимпиадные задачи.
Затем пробный тур:

```bash
python3 trainer.py exam --tasks 6 --minutes 240
```

Тур честный: без ИИ-ассистентов, без чужого кода, четыре часа подряд.
После — `python3 trainer.py score` и разбор ошибок через `hint`.

**Задачи q12–q14** — уровень финала, их стоит решать уже после отбора.

## Веб-версия — ссылка для учеников

Если ставить ничего не хочется, есть та же самая штука в браузере:
ссылку можно просто раздать ученикам. Python там запускается прямо на
странице (Brython), задачи и проверка — те же, что и в консоли.

Исходник веб-версии лежит в `docs/index.html`, её можно открыть и локально,
двойным щелчком по файлу. Файл `docs/tasks.js` собирается из задач командой:

```bash
python3 build_web.py
```

То есть после правки любой задачи в `tasks/` достаточно пересобрать бандл,
и веб-версия обновится вместе с консольной.

## Как это использовать учителю

- Задачи генерируются случайно, поэтому один и тот же `check` у разных
  учеников гоняет разные тесты — решения нельзя просто передать друг другу.
- `trainer.py exam` записывает состав тура и время старта в `.progress.json`;
  файл можно удалить, чтобы начать с нуля.
- `trainer.py hint` показывает авторское решение — полезно для разбора у доски
  после того, как ученики сдались.
- Прогресс хранится локально у каждого ученика в `.progress.json`.

## Папка recipes — для финала

Это заготовки под пять типов задач финала: таблицы, текст, датчики,
изображения, звук, рекомендации, поиск по эмбеддингам. Плюс
`submission_checklist.md` — список проверок формата перед отправкой, на
котором в 2025 году сыпались многие команды.
